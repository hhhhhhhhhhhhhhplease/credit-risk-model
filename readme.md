# 信贷违约预测模型 (Credit Risk Prediction Model)
基于 Kaggle 公开数据集 "Give Me Some Credit" 构建的工业级风控模型，用于金融信贷场景下的用户违约概率预测。

## 项目背景
金融机构需要精准识别高风险信贷用户，以降低坏账率、优化风控策略。本项目通过机器学习方法，对用户历史信贷数据进行建模，预测用户未来两年内发生严重逾期的概率，并提供可解释的业务洞察。

## 技术栈
- **语言**: Python 3.12
- **数据处理**: Pandas, NumPy
- **机器学习**: Scikit-learn, XGBoost, Imbalanced-Learn
- **可解释性**: SHAP
- **可视化**: Matplotlib, Seaborn
- **模型持久化**: Joblib

## 数据集
- 来源: [Kaggle Give Me Some Credit](https://www.kaggle.com/c/GiveMeSomeCredit/data)
- 规模: 10万+ 条用户信贷记录
- 标签: `SeriousDlqin2yrs`（用户未来两年是否发生严重逾期）
- 特征: 10维信贷相关特征（信用卡使用率、逾期次数、收入、负债比等）

## 项目流程
1. **数据清洗**: 处理缺失值、异常值，删除无关特征
2. **特征工程**: 标准化特征，处理样本不均衡（SMOTE过采样+类别权重）
3. **模型训练**: 对比逻辑回归、XGBoost、LightGBM模型，选择XGBoost作为最终模型
4. **超参数调优**: 随机搜索+5折交叉验证，优化模型泛化能力
5. **模型评估**: 以AUC、KS、召回率、精确率为核心指标
6. **可解释性分析**: SHAP分析特征重要性与影响方向
7. **业务落地**: 设计风险分档策略，输出可执行的风控建议
8. **工程化**: 模型持久化保存，可视化输出

## 模型效果
- **交叉验证AUC**: 0.8504
- **测试集AUC**: 0.8482
- **KS值**: 0.5488
- **最佳阈值**: 0.75
- **召回率**: 0.4285
- **精确率**: 0.3984

## 核心发现
1. **核心风险因子**: `RevolvingUtilizationOfUnsecuredLines`（信用卡使用率）是影响违约的最重要特征，使用率越高，违约概率越高。
2. **逾期行为**: 30-59天、60-89天、90天以上逾期次数与违约概率高度正相关。
3. **人口特征**: 年龄越大、收入越高，违约概率越低。
